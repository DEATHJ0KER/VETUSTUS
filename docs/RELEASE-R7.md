## Distribution note

The browser-facing public package may be distributed as ZIP, while the current in-app updater expects the direct setup EXE so it can verify SHA-256 and launch the installer.

## Windows reputation notice

The Beta installer may not be signed with a public Authenticode code-signing certificate. Windows SmartScreen or antivirus products can therefore display a reputation warning even when the file is intact. Verify that downloads originate from `vxd.mobi` and compare the published SHA-256.

Do not disable security software globally just to install the Beta.
